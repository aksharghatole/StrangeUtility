# StrangeUtility

A free, noncommercial collection of practical browser applications. Run locally with `python -m http.server 8000` and open http://localhost:8000. Run `node --test tests/*.test.mjs` to validate the registry and app entry points. See [migration tracker](MIGRATION.md) and [backlog](BACKLOG.md). Imported apps are previews until functional tests and deployment are verified.
