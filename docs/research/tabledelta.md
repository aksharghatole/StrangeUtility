# TableDelta selection
2026-11-25. Existing alternatives include Simon Willison's csv-diff (https://github.com/simonw/csv-diff) and https://www.w3docs.com/tools/csv-compare. Their existence demonstrates an established workflow, not measured demand. Composite-key matching with explicit exclusion of ambiguous records is useful for inventory and contact reconciliation. Existing StrangeUtility tools do not cover this workflow. Reference CSV quoting: https://www.rfc-editor.org/info/rfc4180/ ; spreadsheet formula risks: https://wstg.owasp.org/latest/4-Web_Application_Security_Testing/07-Injection/21-CSV_Injection/ . No external code copied.
Heuristic score (not user research): usefulness 9/10, feasibility 9, demand 7, privacy/cost 10, uniqueness 5, maintainability 9 = 84.5/100 weighted (30/20/15/15/10/10). Chosen for practical scope and no backend; not a novel category. First preview deliberately limited to CSV, strict matching and export; browser test before stable, offline shell and performance profiling later.
