# WaveCut 0.1
Local-first PCM WAV editor: open a recording, inspect min/max waveform, select sample-rounded time range, find non-silent edges, apply linear fades and peak normalization, listen to result and download a fresh WAV. Audio remains in memory. No third-party dependencies or API calls. Generated sample is an original sine wave.
Supports RIFF WAV, mono/stereo integer PCM16, 8–96 kHz, max 40 MiB and five minutes. Does not accept compressed WAV, MP3, RF64, WAVE_FORMAT_EXTENSIBLE, or other encodings. Silence finder measures sample peaks, not speech; it preserves internal pauses. Peak normalization is not loudness normalization. Export drops metadata. No offline reload guarantee in this version. Processing is synchronous and memory-bound; large clips may be slow on older devices. Run a static server from the root; open /apps/wavecut/. Node tests: node --test tests/wavecut.test.mjs. Browser workflow checks upload, edit, download, clear, mobile layout. CI pending.
