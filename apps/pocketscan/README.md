# PocketScan 0.1
Local image scanner with mobile capture input, multi-image import, manual rectangular crop, rotation, grayscale and black-and-white filters, per-page English printed-text OCR, editable text, reordering/deletion, JPEG, A4/Letter image PDF and text export. Eight pages, 15 MiB each, 1,800 pixel long edge. Browser image decoding occurs before dimension validation, so large malformed images can still strain devices. No persistence of documents: save before reload. Does not yet correct perspective, detect edges automatically, support handwriting/multiple languages or make searchable PDFs. Physical camera testing pending.

Run from monorepo root: python apps/pocketscan/prepare_vendor.py then python -m http.server 8000 and open /apps/pocketscan/. The prep step verifies exact npm package SHA-512 archives and extracts only allowlisted files; no lifecycle scripts. First online load installs versioned service worker cache containing OCR code, model, PDF engine and shell. Subsequent offline reopening depends on successful installation and browser cache retention. OCR uses local worker and model with no network service; text and photos are not stored in service-worker cache. CI uses real OCR and checks offline PDF generation, not a mocked engine.
