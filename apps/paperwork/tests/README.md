# Real PDF browser smoke test

Run `python apps/paperwork/prepare_vendor.py` from the monorepo root first. Then: `python -m pip install playwright==1.51.0 pypdf==5.4.0 reportlab==4.4.0`, `python -m playwright install chromium`, then `python apps/paperwork/tests/browser_smoke.py`. Test creates synthetic PDFs in a temporary directory and uses actual integrity-pinned same-origin PDF.js and pdf-lib. Browser requests to other origins are blocked, and offline reload and export are verified; network is required only for dependency preparation and installing test tools. Independent pypdf parser checks output page order, rotation, overlay image and extract count. Chromium emulates mobile dimensions; real device testing still required. Visual text replacement and secure redaction are distinct; test does not claim redaction. No personal documents needed.
